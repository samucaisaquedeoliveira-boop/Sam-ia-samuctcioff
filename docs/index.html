Como instalar o APK no seu Android

  1. Toque no botão BAIXAR APK COMPLETO acima para baixar PortalSam-v1.0.0.apk.
  2. Ao concluir o download, toque na notificação ou abra o arquivo na pasta Downloads do celular.
  3. Se o sistema exibir o aviso de segurança padrão do Android, toque em Configurações → Permitir desta fonte e volte para concluir.
  4. Toque em Instalar, aguarde finalizar e abra o Portal Sam para curtir!
